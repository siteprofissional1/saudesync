# Prompt para Google Stitch — Protótipo Visual Saúde Sync

> **Finalidade:** Geração de mockups de alta fidelidade via Google Stitch mantendo fidelidade estrita ao Design System definido em `directives/design/design.md`.

---

```markdown
Design a modern, high-tech Enterprise HealthTech Web Dashboard named "Saúde Sync" (Intelligent Triage & Real-time Healthcare Flow Management).

### Visual Aesthetic & Theme
- **Color Palette (Dark Mode Primary):**
  - Background Canvas: Deep Obsidian Blue (#07111F)
  - Card & Container Surface: Midnight Navy (#0D1B2A)
  - Card Borders: Subtle Slate (#223A50)
  - Primary Accent: Precision Medical Blue (#2F80ED) and Cyan (#21C7D9)
  - Text: Bright Off-white (#F5F9FC) with Slate secondary (#9FB2C4)
- **Manchester Triage Semantic Tags:**
  - Red / Emergency: #EF4444
  - Orange / Very Urgent: #F97316
  - Yellow / Urgent: #EAB308
  - Green / Less Urgent: #22C55E
  - Blue / Non-Urgent: #3B82F6

### Layout Structure (Desktop & Tablet)
1. **Left Navigation Sidebar (260px width):**
   - Logo: Vibrant Cyan & Blue heartbeat pulse icon + "Saúde Sync"
   - Menu Items with clean outline icons:
     - Dashboard (Overview)
     - Realtime Queue (Fila em Tempo Real - with a pulsing green live dot)
     - Simulated Triage (Triagem Simulada)
     - Analytics (Exploration & P90 metrics)
     - Live External Data (Ourinhos Health Scraping)
     - AI Insights (Gemini Intelligence)
     - About (9 Antigravity Pillars)
   - Bottom status badge: "Backend: Active | Realtime: Synced | Mode: Academic"

2. **Top Header Bar:**
   - Page breadcrumb & view title
   - Quick date/time indicator (America/Sao_Paulo)
   - Dark/Light mode toggle button (Sun/Moon icon)
   - Refresh button

3. **Main Content Dashboard View:**
   - **Row 1 - KPI Grid (4 Cards):**
     * Card 1: Total Patients (1,200) with subtle trend pill
     * Card 2: Waiting in Queue (280) with active badge
     * Card 3: Avg Waiting Time (61.2 min) with P90 indicator (126.1 min)
     * Card 4: SLA Breached / Exceeded (250 patients, 20.8%) in high-contrast orange/red
   - **Row 2 - Interactive Visualizations:**
     * Left Column: Manchester Distribution Donut Chart with clean legends and percentages
     * Right Column: Hourly Volume Area Chart showing peak rush hours
   - **Row 3 - Realtime Queue Summary Table:**
     * Columns: Ticket (ex: A448), Classification Badge (ex: Yellow - Urgent), Elapsed Wait Time (49 min / 60 min limit), Specialty, Bed/Room, Status
     * Subtle pulse effect on rows updated within the last 30 seconds

4. **Footer:**
   - Centered: "Desenvolvido por siteprofissional" (with siteprofissional in crisp blue hyperlink)

Make the interface look premium, surgical, highly readable, and free of unnecessary clutter.
```
